# 🌾 Agribusiness Performance Analysis using SQL

> **Week 3 Project | SQL Data Analyst - Agribusiness Internship**

A SQL-based performance analysis project focused on understanding **crop production, yield, farm performance, seasonal trends and operational costs** using a relational agribusiness database.

---

## 📌 About the Project

Agribusiness performance can vary across crops, farms, seasons and years. This project uses SQL to analyse these differences and turn the available production and cost data into useful business insights.

The analysis focuses on questions such as:

* Which crops have better production efficiency?
* Which farms have higher production and yield?
* How does performance change between years?
* Which seasons perform better?
* Where are the major operational costs?
* How much does it cost to produce one unit?
* How do production, yield, and cost compare across crops?

---

## 🎯 Project Objectives

* Analyse crop production and yield performance
* Compare farm-level performance
* Identify yearly and seasonal production trends
* Analyse operational costs
* Calculate cost per unit of production
* Combine production, yield, and cost to understand overall crop performance
* Generate practical business insights using SQL

---

## 💡 Key Findings

* **Tomato** had the highest yield per acre at **9.00 units**.
* **Wheat** had the highest total production at **1,175 units** in the crop production analysis.
* Total production increased from **1,942.50 units in 2024** to **2,867 units in 2025**.
* **Summer** had the highest average yield at **8.67 units** among the analysed seasons.
* **Labour** was the largest operational cost at **96,500**.
* **Sugarcane** had the lowest overall cost per unit at **6.51**.
* **Mustard** had the highest overall cost per unit at **47.69** and the lowest average yield at **1.50**.

These results show why production alone is not enough to understand crop performance. Yield and cost also need to be considered.
